Top5 starter: where Lab 1 ends
==============================
CWEB2302 Web Development II, Friday 25 Sep 2026

Use this if it is your first class, or your own project is lost or won't run.

What is in it:
  - Home page and nav bar renamed (Views/Home/Index.cshtml, Views/Shared/_Layout.cshtml)
  - Top5Controller with Index(), and Views/Top5/Index.cshtml       (/Top5)
  - Top 5 link in the nav bar
It does NOT have Number(int id) yet. You build that in "Your turn 1".

How to use it:
  1. Unzip it into Documents (next to your own project, not on top of it).
  2. Open Top5.csproj in Visual Studio and press the green Run button (F5).
     Or, in a terminal inside the Top5 folder:  dotnet watch
  3. Open /Top5. It must show your list.
  4. Change the theme and the five items to your own.

The project targets .NET 8 and will also run on any newer .NET installed.
